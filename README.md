# Stéphanie Ongles — maquette de démonstration (non officielle)

Maquette de site réalisée à titre de démonstration pour l'onglerie et boutique **Stéphanie** (Oraison, 04), à partir d'informations publiques (fiche Google, page Facebook).
Ce n'est **pas** le site officiel de l'établissement : aucune réservation ni donnée réelle, version non indexée (`noindex`).
Les photos des sections « Inspirations », « Bijoux, sacs et crèmes » et les plans du film d'accueil sont des images d'illustration de banques libres (Unsplash, Mixkit).
